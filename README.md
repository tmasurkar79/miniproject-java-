# Java Tic-Tac-Toe Game

A simple Tic-Tac-Toe game implementation in Java with a graphical user interface.

## Files

- **miniproject-java-/**: Main project folder containing the Java source code

## How to Run

Navigate to the miniproject-java- folder and execute:

```bash
java Java_tic_tac_toe
```

Or use the provided `run.bat` file on Windows.

## Project Structure

- `Java_tic_tac_toe.java`: Main game application with GUI
- `README.md`: Project documentation
- `run.bat`: Script to run the game on Windows

## Features

- Interactive GUI-based gameplay
- Two-player game mode
- Win detection and game reset functionality
